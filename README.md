# ShimriTouch

אתר One-Pager של **ShimriTouch** — שמרית בן שימול | עיסויים וטיפולי גוף באופקים.

## פתיחה מקומית

אין צורך בהתקנה. פתחי את `index.html` בדפדפן, או הריצי שרת סטטי מתיקייה זו:

```bash
npx --yes serve .
```

## GitHub Pages

האתר סטטי ומוכן ל-Pages משורש המאגר (`index.html` בשורש). הדומיין המותאם הוא `https://shimritouch.co.il/` (קובץ `CNAME` בשורש). האחסון נשאר ב-GitHub Pages; Box מנהל רק את ה-DNS.
