# ShimriTouch

אתר One-Pager של **ShimriTouch** — שמרית בן שימול | עיסויים וטיפולי גוף באופקים.

## פתיחה מקומית

אין צורך בהתקנה. פתחי את `index.html` בדפדפן, או הריצי שרת סטטי מתיקייה זו:

```bash
npx --yes serve .
```

## אירוח

האתר סטטי. GitHub דוחף ל-Netlify (`Deploys from GitHub`). הדומיין המותאם הוא `https://shimritouch.co.il/`. Box מנהל רק את ה-DNS ומפנה ל-Netlify, לא ל-GitHub Pages.
